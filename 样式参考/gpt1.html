Tnine CMS

一个真正长期使用的网站，不应该只是“把页面做出来”。它应该能够容纳文章、生活记录、访客留言，以及那些暂时没有答案的想法。

01 · 从博客到数字花园

Tnine 的核心不是内容类型，而是时间。文章、朋友圈和留言最终都会进入同一条时间线，成为网站生命的一部分。

02 · 前台与后台

前台强调阅读、情绪与个人感受；后台强调效率、数据和可管理性。两套体验应该共享设计语言，但不需要长得一模一样。

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"name": "Tnine", "message": "记录技术、生活和思考"}

03 · 为什么要保留朋友圈

不是每一次生活记录都值得写成文章。朋友圈承担的是更轻的表达：一张照片、一句话、一个完成了的小功能。

04 · 长期维护

颜色、间距、卡片、按钮、输入框和导航都应该由统一 Design System 驱动。以后增加评论、通知、RSS 或更多页面时，只需要复用组件，而不是重新发明样式。

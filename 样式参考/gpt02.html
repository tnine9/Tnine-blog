如何设计一个属于自己的个人博客系统

2026-08-15 · 08min read · 1284 views · commit: 9c41a1e

一个真正长期维护的网站，本质上不是“几张页面”，而是一组结构明确、可以继续演化的系统。

01 / 先定义系统边界

前台负责表达，后台负责管理。文章、朋友圈、留言最终都可以被统一抽象成内容实体，再通过时间线组合起来。

# app/core/config.py
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
  project_name: str = "Tnine"
  environment: str = "production"

settings = Settings()

02 / 时间线比首页更重要

如果把文章、Moment 和 Guestbook 看成三个孤立模块，网站就只是一组功能页面。把它们按时间组合起来，才会真正产生“生活在这里”的感觉。

03 / 为什么程序员做的网站应该有一点工程味

网格、等宽字体、明确的层级、状态信息、日志、版本号，本身就是程序员熟悉的视觉语言。它不需要装饰，它自己就是装饰。

04 / 最重要的是可维护

把颜色、间距、组件和数据接口统一起来，未来新增 RSS、搜索、标签、API、通知或者移动端，只是继续扩展，不是推倒重写。
